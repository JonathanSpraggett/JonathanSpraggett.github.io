**Tools:** Java, Android, IBM Watson API

## Helping job seekers ask better questions

Job Joe was a hackathon application aimed at making information about employers more accessible to Canadian job seekers. Instead of browsing a fixed set of marketing claims, users could ask about factors such as compensation, career opportunities and working conditions.

## Building the prototype

Our team built the Android interface in Java and integrated an IBM Watson chatbot API for conversational responses. The original prototype used IBM's sample application as a starting point and extended it toward an employer-comparison use case.

[View the project on Devpost](https://devpost.com/software/job-joe).

The project introduced me to rapidly integrating an external service into a user-facing product under hackathon time constraints.
